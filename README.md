## 🌟 Core Architecture & Capabilities

### 1. 🧪 The Lab (Research Experiments Dashboard)
- Rigorous scientific inquiry dashboard with hypotheses, methodologies, mathematical formulations (KaTeX), empirical results, and key learnings.
- **Featured Inquiries:**
  - `E-01: Market Regime Detection via Hidden Markov Models` (Gaussian HMM segmentation of trending vs. chop vs. liquidation states)
  - `E-02: LLM Alpha Signal Extraction from SEC 10-K Filings` (Hierarchical vector retrieval and PEAD sentiment scoring)
  - `E-03: Embedding Distance & Two-Pass Prompt Distillation for ATS Optimization` (Production case study behind AI CV Builder)
  - `E-04: Zero-Allocation State Machines for 60FPS Multiverse Physics` (Production case study behind Oops! Game Engine)
  - `E-05: High-Dimensional Vector Norms ($L_p$) & Lasso Regularization Geometry`

### 2. 🛠️ Tools & Products Hub (Live In-Browser Simulators)
- **AI CV Builder v2.0 (Flagship Product):** 10 ATS-optimized templates, Google Gemini AI bullet polishing, profile photo compression, and 1-click clean HD PDF export.
- **Interactive HMM Market Regime Simulator:** Real-time Monte Carlo price path generation and 3-state HMM classification directly in the browser with parameter controls for drift, volatility, and jump shocks.
- **Interactive ATS Resume & Competency Matcher:** Lexical overlap, TF-IDF keyword density, and missing skill extraction against target job descriptions.
- **Quantitative Kelly Criterion & Position Sizing Calculator:** Optimal wealth growth $f^* = \frac{p(b+1)-1}{b}$, fractional Kelly dampening, and 50% drawdown risk estimation.
- **Geometric Vector Norm ($L_p$) Visualizer:** Interactive 2D unit ball transformation canvas ($L_1, L_2, L_\infty$).

### 3. ⚡ Projects Showcase
- Immersive featured showcases (AI CV Builder, Market Regime Suite) and supporting systems (Oops! Chaos Realm, FinDoc, AlgoViz).

### 4. 📚 Knowledge Space & Interactive Knowledge Graph
- Living digital garden with curated mathematical essays and technical breakdowns.
- **Interactive Knowledge Graph:** Canvas-based dynamic network connecting nodes across Computer Science, AI, Quantitative Finance, Mathematics, and Software Engineering.

### 5. ⏱️ Chronological Build Log
- Filterable activity timeline documenting milestones, commit hashes, metrics, and key learnings.

### 6. ⚡ Power User Features
- **Global Command Palette (`⌘K` / `Ctrl+K`):** Instant fuzzy search across all tools, experiments, notes, and actions.
