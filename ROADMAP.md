## 🟢 Phase 1: Core Platform & Identity (Completed)
- [x] Establish dark-first design system with subtle cyan accents and light-mode toggle.

## 🟢 Phase 2: Tools & In-Browser Simulators (Completed)
- [x] Data-driven `tools.js` architecture for scalable tool registries.

- [x] **Geometric Vector Norm ($L_p$) Visualizer:** Interactive unit ball canvas ($L_1, L_2, L_\infty$).

## 🟢 Phase 3: Research Lab & Knowledge Space (Completed)
- [x] **The Lab Dashboard:** Filterable scientific experiment registry with hypotheses, LaTeX formulas, code, and takeaways.
- [x] **Interactive Knowledge Graph:** Canvas-based dynamic network visualizing concept linkages across CS, AI, Math, and Quant Finance.
- [x] **Curated Knowledge Notes:** In-depth technical articles (PCA factor models, Auction Market Theory, Lasso geometry, Prompt distillation).
- [x] **Chronological Build Log:** Filterable activity timeline with commit hashes and milestone metrics.
